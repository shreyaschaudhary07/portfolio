Follow these easy steps to initialize Git and upload this workspace directly to a new repository on your GitHub account:

Step 1: Initialize Local Git git init
Step 2: Add Files & Make Commit git add . && git commit -m "Initial portfolio commit"
Step 3: Rename Branch to Main git branch -M main
Step 4: Link Your Remote GitHub Repo git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
Step 5: Push Files to GitHub git push -u origin main
